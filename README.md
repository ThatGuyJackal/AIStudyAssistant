# AI Study Assistant

An educational AI assistant built with React, Node.js, Ollama, and Llama 3.2.

## Features

- AI-powered explanations
- Example generation
- Study assistance
- Quiz generation

## Technologies

- React
- Node.js
- Express
- Ollama
- Llama 3.2
- GitHub
- Vercel

## Installation

### Install Ollama

Download Ollama from:

https://ollama.com

### Download the Model

```bash
ollama pull llama3.2
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Start the Backend

```bash
node server.js
```

### Start the Frontend

```bash
cd frontend
npm run dev
```

### Open the Application

```text
http://localhost:5173
```

## System Architecture

User
↓
React Frontend
↓
Node.js Backend
↓
Ollama
↓
Llama 3.2
↓
AI Generated Response
